# 📱 FOODIE-EXPRESS — React Native Mobile App

> 🍔 A modern food delivery mobile application built with **React Native, TypeScript, and Expo**.

Foodie-Express is the mobile front end of the Foodie-Express full-stack food delivery system.

The application was implemented from the **Stitch UI/UX design project**:

**Foodie Delivery App UI/UX Design**  
Project ID: `13194954215451445834`

The app connects to the Foodie-Express **Express REST API** and provides a complete food ordering experience with **Light 🌞 and Dark 🌙 modes**.

---
